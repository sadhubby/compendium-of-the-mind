To use opencode, open a terminal and type "opencode" and the CLi will pop up.

To open opencode commands, use ctrl + p

Now in opencode, there are two agents, at least from the installation. They would be Build and Plan agent. According to Seaver, best to use Plan first to fully set all the context and be able to check if the AI is making a correct way of handling the task. You will be able to read it anyway. Consider it as first step always. Afterwards, once the plan is set and it looks good, you can use the Build agent. You can switch agents from the main screen using Tab.

In the commands, there are many possible options but here are most relevant. 

**Prompt > Skills**
This is so you can select the appropriate skill when inputting your prompt.

**Switch Model - ctrl+x m**
Here you are allowed to switch whatever model you are using. 

**Toggle MCPs**
MCPs, Model Context Providers, is an open-source standard for connecting AI applications to external systems.

Using MCP, AI applications like Claude or ChatGPT can connect to data sources (e.g. local files, databases), tools (e.g. search engines, calculators) and workflows (e.g. specialized prompts)—enabling them to access key information and perform tasks.
