To install opencode, there are commands available in their site. 

I would suggest this command as this is one that is available in any operating system
`curl -fsSL https://opencode.ai/install | bash`

However, should you be an npm enjoyer (for some reason you are), this command is used
`npm i -g opencode-ai

Now for arch users, you can either download it using the pacman with
`sudo pacman -S opencode`

Should you not like using pacman, which is understandable because archlinux really takes a while to update with pacman, you can use the paru AUR package manager

`paru -S opencode`

After that, simply open a terminal and type "opencode" and its CLI will then show up.
