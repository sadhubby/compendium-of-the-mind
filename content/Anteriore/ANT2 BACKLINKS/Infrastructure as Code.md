Ability to provide and support computing infrastructure using code instead of manual processes and settings.

Infrastructure components like OS, DB, Storage is time-consuming to setup and is prone to error. Infrastructure as code allows developers to define infrastructure's desired state without doing all that steps. Essentially automation of infrastructure management. 

Automation is the key goal. IaC is used for infrastructure automation to create environments. Common use in SoftDev is to build, test and deploy applications.

Traditional - SysAdmins use scripts and manual processes to set up. IaC automates that setup. You can also duplicate an environment, reduce configuration errors
